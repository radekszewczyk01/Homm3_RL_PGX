# future_work

Ten katalog przechowuje pomocnicze skrypty i dane, które wspierają główny projekt, ale nie są częścią krytycznej ścieżki treningu.

## Zawartość

- `build_npy.py` - generowanie statycznej tablicy LUT.
- `get_data.py` - pobieranie lub przygotowanie danych wejściowych.
- `homm3_creatures_clean.csv` - oczyszczone dane o jednostkach.
- `homm3_static_lut.npy` - gotowa tablica lookup.
- `main.py` - eksperymentalny punkt wejścia.

## Cel

Jeśli coś trafia do `future_work/`, to znaczy, że jest przydatne, ale nie powinno zaciemniać głównego przebiegu projektu w katalogu głównym.
